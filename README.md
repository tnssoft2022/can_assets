# ระบบสร้างวิดีโอและรูปโปสต์อสังหาฯ — Uptown Assets

สร้างวิดีโอและรูปโปสต์โฆษณาทรัพย์จากรูปภาพ พร้อมโลโก้ ราคา รายละเอียด และช่องทางติดต่อ
- วิดีโอ: แนวตั้ง (TikTok / Reels / Shorts) และแนวนอน (YouTube / Facebook)
- รูปโปสต์: ฟีด Facebook / IG (4:5), จัตุรัส (1:1), Story (9:16)
- สตอรี่บอร์ด (Markdown + รูปย่อ) ไว้ตรวจลำดับฉาก ข้อความ และเวลา ก่อน render
- รูปเล็ก/ไม่ชัด ขยายด้วย AI ให้คมขึ้นอัตโนมัติ
- ลบลายน้ำ/แถบข้อความของ Uptown Assets ออกจากรูป
- เพลงประกอบ (แต่งขึ้นเอง ไม่มีปัญหาลิขสิทธิ์) + เสียงพากย์ภาษาไทยจากบทในสตอรี่บอร์ด

## เริ่มต้นใช้งานเร็ว

**จากลิงก์เว็บ (ง่ายที่สุด):** วางลิงก์ uptownassets.com ในแชตของ Claude Code ในโปรเจกต์นี้ เช่น

```
https://www.uptownassets.com/en/project/670-2-storey-townhouse-no-380-on-nut-17-intersection-10-sukhumvit-77
```

→ ได้วิดีโอแนวตั้ง 1 ไฟล์ (มีเพลง + เสียงพากย์) + สตอรี่บอร์ดของวิดีโอ + รูปโปสต์ 1 รูป (ดูหัวข้อ [วิธีที่ 3](#วิธีที่-3--วางลิงก์เว็บให้-claude-สร้างให้))

**จากโฟลเดอร์ทรัพย์ในเครื่อง:**

```bash
# วิดีโอแนวตั้ง ทรัพย์รหัส 205
python3 auto_video.py 205 --style modern --formats vertical

# รูปโปสต์ ทรัพย์รหัส 205
python3 auto_video.py 205 --make poster --style modern

# ทั้งวิดีโอและรูปโปสต์
python3 auto_video.py 205 --make both --style modern --formats vertical

# สตอรี่บอร์ดก่อน (ตรวจแล้วค่อยสร้างวิดีโอ)
python3 auto_video.py 205 --make storyboard --style modern --formats vertical
```

ผลลัพธ์อยู่ที่ `projects/<รหัส>_<ชื่อโครงการ>/output/`

ใช้ได้ทั้ง macOS และ Windows — วิธีติดตั้งบน Windows ดูหัวข้อ [ติดตั้งบน Windows](#ติดตั้งบน-windows)

### ตั้งค่าเครื่อง (`settings.json`)

คัดลอก `settings.example.json` เป็น `settings.json` แล้วแก้ตำแหน่งโฟลเดอร์ทรัพย์:

```json
{
  "source_dir": "/Users/<ชื่อผู้ใช้>/Desktop/footage/assets/UptownAssets_ทรัพย์สิน"
}
```

บน Windows ใช้ `/` หรือ `\\` คั่น path เช่น `"C:/Users/<ชื่อผู้ใช้>/Desktop/footage/assets/UptownAssets_ทรัพย์สิน"`
(หรือระบุทุกครั้งด้วย `--source <โฟลเดอร์>`)

### ฟอนต์

ใช้ **Kanit** จากโฟลเดอร์ `fonts/` — ได้ผลเหมือนกันทุกเครื่อง ทั้ง Mac และ Windows

| ไฟล์ | ใช้กับ |
|---|---|
| `fonts/Kanit-Regular.ttf` | ทำเล, รายละเอียด, ข้อความรอง, ทุกข้อความของสไตล์หรูหรา/มินิมอล |
| `fonts/Kanit-Bold.ttf` | ชื่อโครงการ, ราคา, เบอร์โทร, ป้ายคำบรรยาย (สไตล์ทันสมัย) |

ถ้าไม่มีโฟลเดอร์ `fonts/` ระบบจะใช้ฟอนต์ไทยของเครื่องแทน (ลำดับใน `FONT_CANDIDATES` ของ `make_video.py`):
Leelawadee UI บน Windows → Sukhumvit Set บน macOS (ไม่มีไฟล์ตัวหนา จึงทำตัวหนาด้วยเส้นขอบแทน)

เปลี่ยนเป็นฟอนต์อื่น: วางไฟล์ `.ttf` ตัวปกติและตัวหนาใน `fonts/` แล้วแก้ชื่อไฟล์บรรทัดแรกของ `FONT_CANDIDATES`
(ข้อความย่อลงเองเมื่อยาวเกิน โดยประมาณความกว้างตัวอักษร 0.56 เท่าของขนาดฟอนต์ — ถ้าฟอนต์ใหม่กว้างกว่ามาก ให้ปรับค่าใน `fit_fontsize`)

### ขยายรูปด้วย AI

ไม่บังคับ: Real-ESRGAN (ncnn-vulkan, ~52MB) วางไว้ที่ `tools/realesrgan/`
(ติดตั้งแล้วในเครื่อง Mac นี้ / ถ้าย้ายเครื่องให้ติดตั้งใหม่ด้วยคำสั่งด้านล่าง / Windows ดูหัวข้อติดตั้งบน Windows)
ถ้าไม่มีโปรแกรม ระบบจะแจ้ง `! ข้ามการขยายรูปด้วย AI` แล้วใช้รูปต้นฉบับ

```bash
mkdir -p tools/realesrgan && cd tools/realesrgan
curl -LO https://github.com/xinntao/Real-ESRGAN/releases/download/v0.2.5.0/realesrgan-ncnn-vulkan-20220424-macos.zip
unzip realesrgan-ncnn-vulkan-20220424-macos.zip && chmod +x realesrgan-ncnn-vulkan && rm realesrgan-ncnn-vulkan-20220424-macos.zip
```

### ภาพเคลื่อนไหว (`motion.py`)

ไม่บังคับแต่แนะนำ: ทำให้รูปนิ่งดูเหมือนถ่ายวิดีโอ — ไม่เพิ่ม/แต่งสิ่งที่ไม่มีในรูป
ถ้าไม่มี `.venv` ระบบแจ้ง `! ไม่มี .venv` แล้วใช้การซูม/แพนของ ffmpeg แบบเดิม

```bash
python3 -m venv .venv            # Windows: py -m venv .venv
.venv/bin/pip install torch numpy opencv-python-headless pillow transformers
# Windows: .venv\Scripts\pip install torch numpy opencv-python-headless pillow transformers
```

ครั้งแรกที่สร้างวิดีโอจะดาวน์โหลดโมเดล ~150MB ไว้ที่ `~/.cache/huggingface` (ใช้เชิงพาณิชย์ได้):
Depth Anything V2 Small (Apache-2.0) ประมาณความลึก, UperNet ConvNeXt Tiny (MIT) หาพื้นที่ฟ้า/น้ำ
— เวลาบน Mac M1: วิเคราะห์ ~3 วินาที/รูป (ครั้งเดียว) + สร้างคลิปราว 1 นาทีต่อวิดีโอ 9 ฉาก (เก็บใน cache ใช้ซ้ำ)

## ติดตั้งบน Windows

> ⚠️ โค้ดรองรับ Windows แล้ว แต่ทดสอบจริงบน macOS เท่านั้น — ลองรันบนเครื่อง Windows ก่อนใช้งานจริง

ใช้ **PowerShell** (หรือ Windows Terminal):

**1. ติดตั้ง Python และ ffmpeg**

```powershell
winget install Python.Python.3.12
winget install Gyan.FFmpeg
```

ปิดแล้วเปิด PowerShell ใหม่ แล้วตรวจสอบ:

```powershell
py --version
ffmpeg -version
```

- ffmpeg รุ่น full ของ Gyan มี libfreetype + harfbuzz (จำเป็นสำหรับภาษาไทย)
- ffmpeg 7.1 ขึ้นไปแนะนำ (รุ่นเก่ากว่าระบบจะใช้คำสั่งแบบเก่าให้อัตโนมัติ)

**2. คัดลอกโฟลเดอร์โปรเจกต์** ทั้งโฟลเดอร์ (ต้องมี `fonts/` และ `brand/`) แล้ว `cd` เข้าไป

**3. ตั้งค่า `settings.json`**

```powershell
Copy-Item settings.example.json settings.json
notepad settings.json
```

**4. (ไม่บังคับ) ติดตั้ง Real-ESRGAN รุ่น Windows** — ต้องมีการ์ดจอ/ไดรเวอร์ที่รองรับ Vulkan

```powershell
New-Item -ItemType Directory -Force tools\realesrgan | Out-Null
Invoke-WebRequest https://github.com/xinntao/Real-ESRGAN/releases/download/v0.2.5.0/realesrgan-ncnn-vulkan-20220424-windows.zip -OutFile tools\realesrgan\r.zip
Expand-Archive tools\realesrgan\r.zip -DestinationPath tools\realesrgan -Force
Remove-Item tools\realesrgan\r.zip
```

ต้องได้ไฟล์ `tools\realesrgan\realesrgan-ncnn-vulkan.exe` และ `tools\realesrgan\models\realesrgan-x4plus.bin`

**5. รัน** — บน Windows ใช้ `py` แทน `python3`

```powershell
py auto_video.py 205 --style modern --formats vertical
py auto_video.py 205 --make poster --style modern
```

**ภาษาไทยในหน้าจอเพี้ยน:** ใช้ Windows Terminal หรือตั้งค่าก่อนรัน

```powershell
$env:PYTHONUTF8 = "1"
```

**ความแตกต่างจาก Mac ที่ระบบจัดการให้แล้ว**

| เรื่อง | Mac | Windows |
|---|---|---|
| ฟอนต์ | `fonts/Kanit-*.ttf` | เหมือนกัน (สำรอง: Leelawadee UI) |
| path ใน ffmpeg (`C:\`) | — | แปลงเป็น `C\:/...` ให้อัตโนมัติ |
| Real-ESRGAN | `realesrgan-ncnn-vulkan` | `realesrgan-ncnn-vulkan.exe` |
| โฟลเดอร์ทรัพย์ | `settings.json` | `settings.json` |
| สัญลักษณ์ ✓ ✗ ในคอนโซล | — | แสดงเป็น `?` แทนการ error ถ้าคอนโซลไม่รองรับ |

## ส่วนที่ผู้ใช้ทำ

### วิธีที่ 1 — ใช้ระบบอัตโนมัติ (ทรัพย์ในโฟลเดอร์ UptownAssets_ทรัพย์สิน)

ระบุรหัสทรัพย์ (ตัวเลขหน้าชื่อโฟลเดอร์):

```bash
python3 auto_video.py 205 --style modern --formats vertical
```

ตัวเลือก:

| ตัวเลือก | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `--style` | `luxury` / `modern` / `minimal` / `bold` / `nature` / `corporate` / `night` | `modern` |
| `--formats` | `vertical`, `horizontal` หรือ `vertical,horizontal` | ทั้งสองแบบ |
| `--max-images N` | จำนวนรูปสูงสุดที่ใช้ต่อทรัพย์ | 8 |
| `--music FILE` | ไฟล์เพลงประกอบ | ไม่มีเพลง |
| `--type` | เฉพาะ `rent` (เช่า) หรือ `sale` (ขาย) | ทั้งหมด |
| `--limit N` | ทำแค่ N ทรัพย์แรก | — |
| `--all` | ทำทุกทรัพย์ในโฟลเดอร์ | — |
| `--force` | สร้างใหม่แม้มีไฟล์อยู่แล้ว (และสร้าง `config.json` ใหม่ทับของเดิม) | ข้ามที่มีแล้ว |
| `--config-only` | สร้างแค่ `config.json` ไม่ทำวิดีโอ/โปสต์ | — |
| `--make` | `video` วิดีโอ / `poster` รูปโปสต์ / `storyboard` สตอรี่บอร์ด / `both` = video+poster — คั่นด้วย `,` ได้ เช่น `storyboard,video` | `video` |
| `--poster-size` | `post` 1080×1350 / `square` 1080×1080 / `story` 1080×1920 | `post` |

> ถ้าแก้ข้อความใน `config.json` เอง ให้สร้างใหม่ด้วย `make_video.py` / `make_poster.py` (วิธีที่ 2)
> เพราะ `--force` จะสร้าง `config.json` ใหม่ทับที่แก้ไว้

### วิธีที่ 2 — ทำเองจาก config

ใช้กับโปรเจกต์ที่มี `config.json` อยู่แล้ว (สร้างจากวิธีที่ 1 แล้วแก้ข้อความ)
หรือสร้างโฟลเดอร์ `projects/<ชื่อ>/` ที่มี `config.json` และ `images/` เอง แล้วรัน:

```bash
python3 make_video.py projects/<ชื่อ> --style modern vertical
python3 make_poster.py projects/<ชื่อ> --style modern --size post
python3 make_storyboard.py projects/<ชื่อ> --style modern vertical
```

### วิธีที่ 3 — วางลิงก์เว็บให้ Claude สร้างให้

ใช้ได้กับหน้าโครงการ (`/en/project/<id>-...`) และหน้าทรัพย์ (`/th/view/<id>-...`)
วางลิงก์ในแชตของ Claude Code ที่เปิดโปรเจกต์นี้ — Claude ทำตามขั้นตอนใน `CLAUDE.md` โดยไม่ต้องสั่งเพิ่ม:

1. ดึงข้อมูลจากหน้าเว็บ (ชื่อ, ประเภทห้อง, ขนาด, ราคา, สถานที่ใกล้เคียง)
2. ดาวน์โหลดรูป **ขนาดเต็ม** (`storage/images/projects/...` แทนรูปย่อ `thumbnails/`)
3. ดูรูปทีละรูป → เขียนคำบรรยายให้ตรงรูป, ตรวจลายน้ำ (ลบเฉพาะของ Uptown Assets), ตัดรูปที่ไม่เหมาะออก
   (เช่น รูปซ้ำ, มีลายน้ำบริษัทอื่น, มีบุคคลภายนอกที่จำหน้าได้ — จดเหตุผลไว้ใน `_excluded_images`)
4. สร้าง `projects/<id>_<ชื่อ>/` → `images/` + `config.json` (พร้อมสไตล์แนะนำตามประเภททรัพย์)
5. Claude **เลือกสไตล์ / รูปที่ใช้ / รูปหลักเอง** ตามประเภททรัพย์ แล้วทำต่อทันที (ไม่มีการ์ดเลือก ไม่ต้องรอ)
   — ระบุสไตล์/รูปมาพร้อมลิงก์ได้ เช่น "สไตล์ nature รูปหลัก 03" หรือสั่งเปลี่ยนภายหลัง
6. สร้าง **วิดีโอแนวตั้ง 1 ไฟล์ + สตอรี่บอร์ดของวิดีโอนั้น + รูปโปสต์ 1 รูป** ด้วยสไตล์ที่เลือก
7. แจ้งสิ่งที่ควรตรวจ เช่น ไม่มีราคา (ใส่ "สอบถามราคา"), เบอร์ที่ใช้, รูปที่ตัด/ไม่ใช้

แก้ข้อความหรือรูปภายหลัง: แก้ `config.json` แล้วรัน `make_video.py` / `make_poster.py` (วิธีที่ 2) หรือบอก Claude

### หน้าเลือกสไตล์และรูป (`choose.py`)

ขั้นตอนวางลิงก์ไม่ใช้หน้านี้แล้ว (Claude เลือกให้เองและบันทึกด้วย `--apply`) — ยังเปิดหน้าเว็บในเครื่องเองได้ถ้าต้องการเลือกด้วยตัวเอง มี 2 แบบ:

| แบบ | คำสั่ง | ใช้เมื่อ |
|---|---|---|
| **การ์ดในแชต** (เลิกใช้ในขั้นตอนอัตโนมัติ — ช้าและรูปย่อแสดงไม่ครบ) | `python3 choose.py <โครงการ> --widget` | — |
| **หน้าเว็บในเครื่อง** | `python3 choose.py <โครงการ>` (เปิดเบราว์เซอร์ให้เอง) | รันเองไม่ผ่าน Claude, ใช้บน Windows |

```bash
python3 choose.py projects/<โครงการ> --timeout 30                       # นับถอยหลัง 30 วินาที
python3 choose.py projects/<โครงการ> --apply --style nature --images 05.jpeg,02.jpeg --main 05.jpeg   # บันทึกผลเลือกเอง
```

การ์ดในแชตใช้รูปย่อขนาดเล็ก (ฝังในการ์ด ประมาณ 20KB) — ตอบกลับมาในแชตเป็นข้อความ
`เลือกแล้ว [<โฟลเดอร์>] สไตล์: … | รูป: … | รูปหลัก: …` แล้ว Claude บันทึกด้วย `--apply`
หน้าเว็บในเครื่อง (`http://localhost:8765`, พอร์ตไม่ว่างจะใช้พอร์ตถัดไป) บันทึกลง config เองเมื่อเลือกเสร็จ

ทั้งสองแบบมี 3 ส่วน:

1. **สไตล์** — การ์ด 7 ใบ แต่ละใบมีภาพจำลองโปสต์จากรูปหลักจริง + สีของสไตล์ / ใบที่แนะนำมีป้าย "แนะนำ"
2. **รูปที่จะใช้** — รูปย่อทุกรูป ติ๊ก "ใช้รูปนี้" ไว้ให้ตามค่าแนะนำ (รูปที่ไม่แนะนำแสดงเหตุผล เช่น ลายน้ำบริษัทอื่น)
3. **รูปหลัก** — ฉากแรกของวิดีโอ + รูปใหญ่ในโปสต์ (★ = แนะนำ)

- **นับถอยหลัง 20 วินาที** → ไม่มีการเลือก = ใช้ค่าแนะนำ / กดเลือกอะไรก็ตาม = **หยุดนับ** รอกด "ยืนยัน"
- ปุ่ม "ใช้ค่าแนะนำ" = ยืนยันค่าแนะนำทันที
- ผลบันทึกลง `config.json`: `style`, `images` (รูปหลักเป็นฉากแรก — สลับคำบรรยาย/บทพากย์ให้ฉากแรกเป็นบทเปิดเสมอ), `poster_images`
- **ค่าแนะนำ**: สไตล์จาก `recommended_style` (Claude ตั้งหลังดูทรัพย์) หรือเดาจากประเภททรัพย์ — ที่ดิน/บ้านเดี่ยว → `nature`,
  อาคาร/ออฟฟิศ → `corporate`, ราคาสูง/เพนท์เฮาส์ → `night`, ราคาถูก → `bold`, อื่น ๆ → `modern` /
  รูป = รูปใน `images` ของ config / รูปหลัก = รูปแรกของ `poster_images`
- ไม่มีใครเปิดหน้าเลือกภายใน 10 นาที → ใช้ค่าแนะนำแล้วจบโปรแกรม

## ส่วนที่ระบบทำ

### 1. อ่านข้อมูล (`auto_video.py` หรือ Claude จากลิงก์เว็บ)

- อ่าน `รายละเอียด.txt` → ชื่อโครงการ, ราคาเช่า/ขาย, ห้องนอน, ห้องน้ำ, ขนาด, ชั้น, ตึก, เบอร์ฝ่ายขาย
- ดึงจุดขายจาก "รายละเอียดห้อง" ที่ฝ่ายขายเขียน เช่น วิว, ทิศ, โอน 50:50, สถานที่ใกล้เคียง
- กรองข้อความที่ไม่ใช่จุดขายออก (เรื่องโคเอเจนท์, ข้อห้ามต่าง ๆ)
- ตัดชื่อโครงการที่ยาวเกินให้สั้นลง
- เลือกรูป 8 รูปแรกในโฟลเดอร์ (ใช้จากโฟลเดอร์ต้นฉบับโดยตรง ไม่คัดลอก)
- บันทึกเป็น `projects/<รหัส>_<ชื่อ>/config.json` — **แก้ข้อความได้** แล้วสร้างใหม่ด้วยวิธีที่ 2

> หมายเหตุ: รายการเฟอร์นิเจอร์และสิ่งอำนวยความสะดวกใน `รายละเอียด.txt`
> เหมือนกันทุกทรัพย์ (เป็นชุดไอคอนจากหน้าเว็บ) จึงไม่นำมาใช้

### 2. ลบลายน้ำ / ตัดขอบ (`cleanup.py`)

ทำเฉพาะรูปที่กำหนด `crop` หรือ `remove` ใน `config.json` (ทำก่อนขยายด้วย AI):

```json
{ "file": "01.webp", "crop": [0, 0.20, 1, 0.675] }
{ "file": "05.webp", "remove": [[0.80, 0.90, 0.18, 0.08]] }
```

- ตัวเลขเป็นสัดส่วนของรูปต้นฉบับ `[x, y, กว้าง, สูง]` (0–1) — เช่น `0.20` = 20% จากขอบบน
- `crop` — เก็บเฉพาะส่วนนี้ ตัดแถบ/ข้อความริมรูปทิ้ง (ภาพคมที่สุด)
- `remove` — ลบลายน้ำเล็ก ๆ ในกรอบ เติมจากพื้นที่รอบ ๆ (ffmpeg `delogo`) — กรอบใหญ่จะเห็นเป็นรอยเบลอ
- ผลเก็บไว้ใน `projects/<โครงการ>/cache/cleaned/`

> ลบเฉพาะลายน้ำ/แบรนด์ของ Uptown Assets เอง — ลายน้ำของบริษัทอื่นบอกความเป็นเจ้าของรูป
> ไม่ควรลบ ให้เอารูปนั้นออก (ระบุใน `_excluded_images` เพื่อจดเหตุผล) หรือขออนุญาตเจ้าของก่อน

### 3. เช็คภาพไม่ชัด → ขยายรูปด้วย AI (`upscale.py`)

**วิธีเช็ค: ดูจากขนาดรูป**

| ด้านยาวของรูป | ผล | สิ่งที่ระบบทำ |
|---|---|---|
| น้อยกว่า 1920px | ต้องขยายเพื่อให้เต็มจอ → ภาพเบลอ | ขยายด้วย AI |
| ตั้งแต่ 1920px ขึ้นไป | ชัดพอสำหรับวิดีโอ 1080p | ใช้รูปต้นฉบับ |

- เกณฑ์ 1920px = ด้านยาวของวิดีโอ (1080×1920) — ค่าอยู่ที่ `MIN_LONG_SIDE` ใน `upscale.py`
- รูปจากเว็บ uptownassets.com ส่วนใหญ่กว้าง 800px จึงถูกขยายแทบทุกรูป
- ข้อจำกัด: รูปที่ใหญ่พอแต่ถ่ายมาเบลอ/โฟกัสหลุด จะไม่ถูกตรวจพบ
  (ลองวัดความเบลอด้วย `blurdetect` ของ ffmpeg แล้ว ค่าขึ้นกับเนื้อหาในรูปมากเกินไป เช่น ผนังขาวโล่งถูกนับว่าเบลอ จึงไม่ใช้)

**การขยาย**

- ขยาย 4 เท่าด้วย Real-ESRGAN (โมเดล x4plus สำหรับรูปถ่าย)
- ผลเก็บไว้ใน `projects/<โครงการ>/cache/upscaled/` — รูปเดิมใช้ซ้ำได้ทันที ไม่ต้องขยายใหม่
- ชื่อไฟล์ใน cache คำนวณจากเนื้อหารูป จึงย้ายหรือเปลี่ยนชื่อโฟลเดอร์โครงการได้โดยไม่ต้องขยายใหม่
- ลบโครงการ = ลบ cache ของโครงการนั้นไปด้วย / ลบเฉพาะ `cache/` ได้ถ้าต้องการพื้นที่ (สร้างใหม่อัตโนมัติ)
- ใช้เวลาประมาณ 25 วินาทีต่อรูป (ครั้งแรกเท่านั้น, Apple M1)
- ใช้กับทั้งวิดีโอและรูปโปสต์ / ปิดได้ด้วย `"ai_upscale": false`
- ถ้าไม่มีโปรแกรมใน `tools/realesrgan/` ระบบจะข้ามขั้นตอนนี้และใช้รูปต้นฉบับ
- ข้อจำกัด: ตัวอักษรเล็กมากในรูป (เช่น ป้าย, ปลั๊กไฟ) อาจเพี้ยน

### 4. เตรียมภาพ (`make_video.py` + `grade.py` + `motion.py`)

- **แต่งโทนสี** (ใช้กับวิดีโอและโปสต์):
  1. ปรับทุกรูปให้เข้าชุด — ดึงความสว่าง คอนทราสต์ และสมดุลแสงขาว เข้าหาค่ากลางของทั้งชุดแบบครึ่งทาง
     ปรับสีแต่ละช่องได้ไม่เกิน ±6% และไม่นับท้องฟ้า → สีผนัง/วัสดุยังเป็นสีจริง ฟ้ายังเป็นสีฟ้า
  2. โทนประจำสไตล์แบบอ่อน ๆ — ทันสมัย สด / หรูหรา อุ่น คอนทราสต์ลึก / มินิมอล สว่าง สีจาง /
     ป้ายเซล อิ่มสี / ธรรมชาติ อุ่น ออกเขียว / ทางการ สีกลาง / หรูกลางคืน เย็น ออกฟ้า
  — ปิดด้วย `"grade": false` หรือใช้เฉพาะข้อ 1 ด้วย `"grade": "match"` / ปิดบางรูป `images[].grade: false`
- ปรับขนาดภาพให้เต็มจอด้วย lanczos
- **กล้อง** (เลือกเองตามรูป หรือกำหนด `motion` ต่อรูป): ฉากแรกซูมเข้าหาตัวทรัพย์ / รูปที่เห็นฟ้า เงยกล้องขึ้น /
  สระ-ทะเล เลื่อนข้าง / ห้อง สลับเลื่อน-ซูมเข้า-ซูมออก — ซูมเข้าหา**จุดโฟกัส** (บริเวณที่ไกลที่สุดของห้อง หรือ `focus`)
  เคลื่อนแบบนุ่ม (ค่อย ๆ เริ่ม ค่อย ๆ หยุด)
- **ภาพ 2.5D**: ฉากหน้าขยับมากกว่าฉากหลังตามความลึก (`parallax` 0 = ปิด, 1 = ปกติ)
- **เอฟเฟกต์เฉพาะจุด**: ผิวน้ำในสระกระเพื่อมเบา ๆ / เมฆบนฟ้าเลื่อนช้า ๆ (หาพื้นที่ให้อัตโนมัติ, `effects` กำหนดเอง)
- **แสงวิ่ง** ผ่านรูปฉากแรกหนึ่งครั้ง (`sweep`)
- **แบ่งจอ**: `"with": "08.jpg"` = 2 รูปในฉากเดียว (บน/ล่าง หรือ ซ้าย/ขวา) รูปที่สองเลื่อนเข้ามา
- ข้อความลอยขึ้นเข้าที่ตอนปรากฏ
- ไม่มี `.venv`: ซูม/แพนของ ffmpeg / วิดีโอแนวนอน + รูปแนวตั้ง → วางรูปกลางจอบนพื้นหลังเบลอ (ทั้งสองกรณี)

### 5. ต่อภาพ

- เปลี่ยนภาพสลับกันในชุดของสไตล์ (เช่น ทันสมัย: สไลด์ซ้าย → สไลด์ขึ้น → ซูมทะลุ → เลื่อนนุ่ม) — ตั้ง `transition` = ใช้แบบเดียว
- ต่อท้ายด้วยฉากปิด (รูปสุดท้ายแบบเบลอ)

### 6. ใส่องค์ประกอบ

- **โลโก้** — มุมขวาบนตลอดวิดีโอ และโลโก้ใหญ่กลางฉากปิด
- **ช่วงเปิด** — ชื่อโครงการ + ทำเล
- **ตลอดวิดีโอ** — ราคา + รายละเอียดห้อง
- **แต่ละรูป** — คำบรรยาย / จุดขาย
- **ฉากปิด** — ชื่อโครงการ, ราคา, รหัสทรัพย์, เบอร์โทร, LINE

### 7. ใส่เสียง (เพลง + เสียงพากย์)

**เสียงพากย์** (`voice.py`) — จากบท `images[].narration` และ `outro_narration` ใน `config.json`

- สร้างด้วย **Botnoi Voice V4 (Expressive)** (เสียงไทยธรรมชาติ ตัดเสียงหายใจหัว/ท้ายให้, ใช้แต้มของบัญชี Botnoi — ประมาณ 0.2 แต้ม/ตัวอักษร, 1 ประโยค ≈ 12 แต้ม)
  - ใส่ token ใน `settings.json` → `"botnoi_token": "..."` (หรือตัวแปรแวดล้อม `BOTNOI_TOKEN`) — รับ token ที่ https://voice.botnoi.ai/developer/api
  - ค่าเริ่มต้น: V4 ผู้พูด `"2"` (Ava) — ดูรายชื่อผู้พูดทั้งหมด: `python3 voice.py --speakers`
  - ใช้รุ่นเดิม (V2): `"voice": {"version": "v2", "speaker": "8"}` — **เลขผู้พูดแต่ละรุ่นไม่ตรงกัน** (Ava = 2 ใน V4, = 8 ใน V2)
- สำรอง (ใช้เมื่อไม่มี token / แต้มหมด / ไม่มีเน็ต — ระบบแจ้ง `! สร้างเสียงด้วย botnoi ไม่ได้`):
  **edge-tts** (ฟรี, ติดตั้ง `python3 -m pip install edge-tts`, เสียง `th-TH-PremwadeeNeural` / `th-TH-NiwatNeural`)
  → คำสั่ง `say` ของ macOS เสียง **Kanya** → ไม่มีเลย = ข้ามเสียงพากย์ (แจ้ง `! ข้ามเสียงพากย์`)
- แปลงคำอ่านให้เอง: `฿15,000` → "15,000 บาท", `ตร.ม.` → "ตารางเมตร", `/เดือน` → "ต่อเดือน",
  เบอร์ `064-535-9426` → "ศูนย์หกสี่ ห้าสามห้า เก้าสี่สองหก", `1–3` → "1 ถึง 3"
- **ความยาวแต่ละฉากปรับตามเสียงพากย์** (อย่างน้อยเท่าค่าของสไตล์) — พูดจบก่อนเปลี่ยนภาพเสมอ / ฉากปิดยาวขึ้นตามบทฉากปิด
- ชื่อภาษาอังกฤษควรเขียนเป็นคำอ่านไทยในบท เช่น "พีเพิล พาร์ค", "อัพทาวน์ แอสเซ็ทส์"
- เก็บไฟล์เสียงไว้ใน `projects/<โครงการ>/cache/voice/` (สร้างใหม่เมื่อบทเปลี่ยน)
- ทดลองฟัง: `python3 voice.py "ข้อความที่ต้องการฟัง"` / ผู้พูดอื่น `--speaker 31` / เทียบ V2 `--version v2 --speaker 8` / edge `--engine edge --voice th-TH-NiwatNeural` / เสียงเดิม `--engine say`

**เพลงประกอบ**

- ไม่ระบุ `music` → ใช้ `brand/music/<สไตล์>.mp3` อัตโนมัติ / `"music": "ไฟล์.mp3"` ใช้เพลงอื่น / `"music": false` ไม่มีเพลง
- เพลงใน `brand/music/` แต่งขึ้นด้วย `make_music.py` (สังเคราะห์เสียง ไม่มีลิขสิทธิ์ของคนอื่น):
  `luxury` เปียโนคอร์ดแจ๊สช้า / `modern` จังหวะสนุก มีกลองเบส / `minimal` ดีดเบา ๆ + เชคเกอร์ /
  `bold` เร็ว คีย์ไมเนอร์ เบสหนัก / `nature` กีตาร์ดีดช้า อบอุ่น / `corporate` เปียโนจังหวะกลาง / `night` เปียโนไมเนอร์ช้า
  — สร้างใหม่: `python3 make_music.py` (หรือระบุสไตล์ เช่น `python3 make_music.py night`)
- เพลงวนเองถ้าวิดีโอยาวกว่าเพลง, fade-in 1 วินาที, fade-out 2 วินาที
- **มีเสียงพากย์ → เพลงเบาลงอัตโนมัติตอนพูด (ducking)** แล้วดังกลับเมื่อหยุดพูด
- ไม่มีทั้งเพลงและเสียงพากย์ → ใส่แทร็กเสียงเงียบ (บางแพลตฟอร์มอัปโหลดไม่ผ่านถ้าไม่มีแทร็กเสียง)

### 8. บันทึกไฟล์

- แนวตั้ง 1080×1920 / แนวนอน 1920×1080, 30 fps

## รูปโปสต์ (`make_poster.py`)

ใช้ข้อมูล สไตล์ โลโก้ และรูปที่ขยายด้วย AI ชุดเดียวกับวิดีโอ ได้รูป JPG 1 รูป มี 6 แบบจัดวาง

**เลือกแบบอัตโนมัติ:** ถ้าไม่ได้ตั้ง `poster_layout` ระบบจะเลือกจากชื่อโฟลเดอร์โปรเจกต์ ตามจำนวนรูปที่มี
(3 รูปขึ้นไป: collage/grid/split/magazine/frame · 2 รูป: collage/magazine/frame · 1 รูป: single/magazine/frame)
โปรเจกต์เดิมจึงได้แบบเดิมทุกครั้งที่สร้างใหม่ แต่ละโครงการได้แบบไม่เหมือนกัน
ลองแบบอื่นได้ด้วย `python3 make_poster.py <โปรเจกต์> --layout grid` หรือตั้ง `"poster_layout": "grid"` ใน config

| แบบ | ลักษณะ |
|---|---|
| `collage` | รูปหลักใหญ่ + รูปเล็กเรียงแถว + แถบข้อมูลด้านล่าง |
| `grid` | ตาราง 2×2 (3 รูป = รูปแรกเต็มแถวบน) + แถบสี + แถบข้อมูลรวมชื่อโครงการ |
| `split` | รูปหลักใหญ่ซ้าย (ชื่อโครงการท้ายรูป) + รูปเล็ก 2 รูปเรียงขวา + แถบข้อมูลด้านล่าง |
| `magazine` | รูปเต็มหน้า ชื่อตัวใหญ่ด้านบน + รูปเล็กมีกรอบ + แถบราคาเต็มความกว้าง |
| `frame` | รูปในกรอบสีบนพื้นสีของสไตล์ + ข้อความจัดกึ่งกลาง (เหมาะกับรูปเล็ก/ไม่คม) |
| `single` | รูปเดียวเต็มกรอบ ข้อความทับบนรูป |

**collage — หลายรูป**

1. รูปหลักใหญ่ด้านบน พร้อมโลโก้มุมขวาบนและป้ายจุดขายมุมซ้ายบน
2. ชื่อโครงการ + ทำเล ท้ายรูปหลัก (มีเงาไล่สีให้อ่านง่าย)
3. รูปเล็กเรียงแถว สูงสุด 3 รูป
4. แถบข้อมูลด้านล่าง: ราคา → รายละเอียด → เบอร์โทร → รหัสทรัพย์
   (ข้อความย่อลงเองถ้าพื้นที่ไม่พอ / มินิมอลใช้แถบสีขาว สไตล์อื่นใช้แถบสีเข้ม)

**single — รูปเดียว** (ตั้ง `"poster_layout": "single"`)

รูปเดียวเต็มกรอบ ข้อความทั้งหมดอยู่บนรูปพร้อมเงาไล่สี

**เลือกรูปเอง:** `"poster_images": ["03.jpeg", "04.jpeg", "05.jpeg", "02.jpeg"]`
(รูปแรก = รูปหลัก ที่เหลือ = รูปเล็ก) ถ้าไม่กำหนดจะใช้รูปตามลำดับในโฟลเดอร์

ขนาด story เว้นขอบล่างไว้ให้พ้นปุ่มตอบกลับของ IG / Facebook

ไฟล์อยู่ที่ `projects/<รหัส>_<ชื่อ>/output/<ชื่อ>_<สไตล์>_poster_<ขนาด>.jpg`

## สตอรี่บอร์ด (`make_storyboard.py`)

ไฟล์ Markdown สำหรับตรวจวิดีโอก่อน render จริง (สร้างเร็ว ไม่ต้องขยายรูปด้วย AI)
เวลาและการจัดภาพคำนวณด้วยฟังก์ชันเดียวกับ `make_video.py` (`timeline()`, `clip_mode()`) จึงตรงกับวิดีโอจริงเสมอ

**ในไฟล์มี**

1. ข้อมูลสรุป: ขนาด, สไตล์, ความยาวรวม, วินาทีต่อฉาก, การเปลี่ยนภาพ, เพลง, โลโก้
2. ข้อความที่แสดงตลอดวิดีโอ พร้อมช่วงเวลา (ชื่อโครงการ, ทำเล, ราคา, รายละเอียด)
3. ตารางฉาก — แต่ละฉากมี:
   - รูปย่อ (ตัดตามสัดส่วนจอเหมือนวิดีโอ)
   - เวลาเริ่ม–จบ (วินาที)
   - ไฟล์รูป, การเคลื่อนกล้อง (ซูม / แพนซ้าย→ขวา / วางกลาง + พื้นเบลอ), การเปลี่ยนภาพไปฉากถัดไป
   - ข้อความบนจอ (ชื่อ, ทำเล, ป้ายคำบรรยาย)
4. ฉากปิด: โลโก้, ราคา, ข้อมูลติดต่อ
5. ตารางบอกว่าต้องแก้ค่าไหนใน `config.json`

**ไฟล์ที่ได้**

```
projects/<รหัส>_<ชื่อ>/output/<ชื่อ>_<สไตล์>_<ขนาด>_storyboard.md
projects/<รหัส>_<ชื่อ>/output/storyboard/<สไตล์>_<ขนาด>/scene01.jpg ... outro.jpg
```

**ขั้นตอนที่แนะนำ:** สร้างสตอรี่บอร์ด → ตรวจ → แก้ `config.json` (ลำดับรูป, ป้าย, ข้อความ) → สร้างสตอรี่บอร์ดใหม่ → พอใจแล้วค่อยสร้างวิดีโอ
(สตอรี่บอร์ดเป็นไฟล์อ่านอย่างเดียว — แก้ในไฟล์ .md จะไม่มีผลกับวิดีโอ)

| รูปไม่ชัด | ตรวจว่ามี `tools/realesrgan/realesrgan-ncnn-vulkan` และไม่ได้ตั้ง `"ai_upscale": false` / ดีที่สุดคือใช้รูปต้นฉบับขนาดใหญ่ |
| รูปใหญ่แต่เบลอ ไม่ถูกขยาย | ระบบเช็คจากขนาดรูปเท่านั้น รูปที่ใหญ่ตั้งแต่ 1920px จะถูกข้ามเสมอ — ให้เปลี่ยนเป็นรูปอื่นที่ชัดกว่า |
| ครั้งแรกช้า | ขยายรูปด้วย AI ~25 วินาที/รูป ครั้งต่อไปใช้จาก `projects/<โครงการ>/cache/upscaled/` |
| ไม่สร้างไฟล์ใหม่ ("มีไฟล์อยู่แล้ว ข้าม") | ลบไฟล์ใน `output/` หรือใช้ `--force` |
| ข้อความยาวเกินจอ | ตัวอักษรย่อลงเองอัตโนมัติ ถ้ายังยาวไปให้แก้ข้อความใน `config.json` |
| รูปโปสต์รูปหลักไม่สวย | กำหนด `poster_images` เลือกรูปเอง |
| ไม่อยากได้โลโก้ | ตั้ง `"logo": false` |
| "ไม่พบโฟลเดอร์ทรัพย์" | ตั้ง `source_dir` ใน `settings.json` หรือใช้ `--source` |
| "ไม่พบ ffmpeg" | ติดตั้ง ffmpeg (Mac: `brew install ffmpeg` / Windows: `winget install Gyan.FFmpeg`) แล้วเปิดเทอร์มินัลใหม่ |
| ภาษาไทยเป็นกล่อง ▯ | ffmpeg ไม่มี harfbuzz — ใช้รุ่น full / ตรวจว่ามีโฟลเดอร์ `fonts/` |
| ไม่มีเสียงพากย์ | ใส่ `narration` ในรูป / ตรวจว่าไม่ได้ตั้ง `"voiceover": false` / ใส่ `botnoi_token` ใน `settings.json` (หรือติดตั้ง edge-tts) และต่อเน็ต |
| เสียงพากย์อ่านผิด | เขียนบทเป็นคำอ่านไทย หรือเพิ่มกฎใน `speakable()` ของ `voice.py` / ทดลองฟังด้วย `python3 voice.py "..."` |
| วิดีโอยาวเกินไป | บทพากย์ยาว → ตัดบทให้สั้นลง หรือเพิ่ม `voice.speed` (เช่น `1.1`) |
| ไม่มีเพลง | ตรวจว่าไม่ได้ตั้ง `"music": false` และมีไฟล์ `brand/music/<สไตล์>.mp3` (สร้างด้วย `python3 make_music.py`) |
| โครงการไม่ขึ้น GitHub | ตั้งใจไว้ — `projects/.gitignore` กันทุกโครงการ ให้คัดลอกโฟลเดอร์ `projects/` เองถ้าต้องการย้ายเครื่อง |
